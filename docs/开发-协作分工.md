# 开发协作与分工

> 目的只有一个：**两个人同时改这个工程，不会出现「你编译通过、他一进游戏就崩」**。
> 下面每一条都是已经踩过的坑，不是规范洁癖。

## 1. 三个产物，各管一段

| 产物 | 源码位置 | 职责 | 谁改它 |
|---|---|---|---|
| `PeakMusic.dll` | `PeakMusic/PeakMusic/` | Unity 侧：面板逻辑、播放器、3D 歌词渲染、特效层、样式表 | 内核负责人 |
| `PeakMusic.Core.dll` | `.workbuddy/tmp/peaksrc/PEAK-Source/Core/`（**注意，不是仓库里的 `PeakMusic.Core/`**） | 网易云 / QQ 接口、登录、取流、歌词时间轴 | 接口负责人 |
| `PeakMusic.UI.dll` | `.workbuddy/tmp/peaksrc/PEAK-Source/UI/`（独立工程，**不在 .sln 里**） | IMGUI 面板全部页面（首页 / 播放页 / 样式页 / 歌单页） | UI 负责人 |

`PeakMusic/PeakMusic.Core/` 是**早期简化版**，只作为插件工程的编译引用；真正部署的是上面那个 peaksrc 版。

## 2. 最大的坑：Core 有两份源码

插件 `ProjectReference` 的是仓库版 Core，但游戏里跑的是 peaksrc 版 Core。

- 只改仓库版 → 插件编译通过，**进游戏 `MissingMethodException`**
- 只改 peaksrc 版 → 插件编译报错（找不到新方法）

**规则：动 Core 的任何 public 成员，两个位置必须同时改，然后两个工程都编。**
只改实现、不动签名，才允许只改 peaksrc 版。

## 3. UI 是独立程序集，靠反射读内核

UI 不能直接 `new MusicPanel()`，所有交互走 `Reflect`：

- 读字段：`R.G<T>("字段名", 默认值)` —— **只查字段，不查属性**
  （踩过：内核有 `Client` 属性、字段叫 `_client`，UI 读 `"Client"` 永远拿 null）
- 写字段：`R.S("字段名", 值)`
- 调方法：`R.Call("方法名", 参数...)`

**规则：UI 要用新数据，先在内核里加一个 `internal` 字段或方法，再在 UI 里读；不要在 UI 里自己算。**

## 4. 并行安全区 / 冲突高发区

**可以放心并行**（几乎不冲突）

- 样式表 `LyricColors.cs` 里**追加**预设（只在数组末尾加，不动别人那几行）
- `StylePage` 新增一栏（颜色 / 特效 / 未来的新页）
- 文案、README、CHANGELOG、商店截图
- 新增独立文件（如 `Icons.cs`、`FlacLoader.cs`）：先建文件，最后再接一行调用

**必须打招呼再动**（改一处影响全局）

| 文件 | 为什么 |
|---|---|
| `WorldLyricRenderer.cs` | 歌词每帧逻辑，改错就是整段不显示 |
| `MusicPanel.Update()` | 每帧主循环，少一行就整个面板停摆（真踩过） |
| `Layout.cs` | 所有控件坐标，一改全页错位 |
| `Plugin.cs` 的 cfg 键名 | 改名=玩家配置全丢 |
| `csproj` 的 Deploy 目标 | 改错会把 DLL 拷错地方 |

## 5. 六条铁律（都是血）

1. **游戏运行时不能覆盖 DLL**：DLL 被内存映射，`Copy-Item` 必失败。先关游戏。
2. **面板热键默认 F1**，但本机 cfg 里是 F4（F1 被别的模组占了）。别在代码里写死。
3. **日志单行别超 2000 字符**：BepInEx 控制台会抛 `IndexOutOfRange`，还会毒化后续所有插件。
4. **cfg 新键不会自动补默认值**给老用户：改默认值要用一次性迁移标记（`[内部] XxxMigrated`）。
5. **不要用 emoji 当图标**：`⏸`/`⏭` 在 Windows 会被 Segoe UI Emoji 画成蓝方块。用 `Icons.Draw()`。
6. **Unity 6 的 `AudioClip.SetData` 返回 `bool`**，反射绑定时必须按返回类型选委托，否则静默退回 320k。

```

[ ] 进游戏按 F1(或F4) 能开面板
[ ] 放一首歌：歌词出得来、逐字点亮、没有 Exception
[ ] 日志里 grep "[UI] 字段缺失" / "Exception" / "MissingMethod" 都是 0
```

## 7. 常用命令

```powershell
# 内核（不自动部署时加 -p:SkipDeploy=true）
C:\Users\Admin\.dotnet\dotnet.exe build PeakMusic\PeakMusic\PeakMusic.csproj -c Release -p:SkipDeploy=true

# Core
cd .workbuddy\tmp\peaksrc\PEAK-Source\Core
C:\Users\Admin\.dotnet\dotnet.exe build PeakMusic.Core.csproj -c Release

# UI
cd .workbuddy\tmp\peaksrc\PEAK-Source\UI
C:\Users\Admin\.dotnet\dotnet.exe build PeakMusic.UI.csproj -c Release
```

部署 = 把三个 DLL 拷到 `D:\Steam\steamapps\common\PEAK\BepInEx\plugins\PeakMusic\`，
**四个一起才算完整**（少 `FlacBox.dll` 无损会静默退回 320k，少 Core/UI 插件直接不加载）。
